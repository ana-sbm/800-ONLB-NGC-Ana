\section{Lifecycle and Review Gates}
Use bounded iterations within the V-model described in
\hyperref[Figure:VModel]{the lifecycle figure}. First review the mission,
boundary, stakeholders, and open questions; next develop linked candidate
requirements and planned tests; then review architecture and implementation
increments. Verification needs observed compliance evidence, validation
needs stakeholder observations, and release needs a human decision.
Later architecture views and hardware-specific budgets are planned until
their inputs and risks justify specific designs and allocations.

\section{Initialization Decisions and Open Questions}
\label{Section:SP800OpenQuestions}
The project name, owner, filename prefix, scope, and profile decision are
confirmed. The organization is \Organization. Course review authority beyond the project
owner remains to be confirmed. Every question below is owned by A. Crone; resolve it
before its dependent requirements or implementation are approved.
\begin{enumerate}
\item Confirm stakeholder needs and downstream publication semantics,
including validity and freshness interpretation.
\item Identify hardware and board revisions, ADC and counter capture rules,
counter width and rollover, byte pairing, and data representation. A counter
input is not evidence of an acquisition timestamp.
\item Identify the target host operating system, FT245R driver and SDK,
supported device mode, programming language, compiler, and runtime.
The document-build host is Windows; this does not select the product platform.
\item Supply controlled datasheets, schematics, interface definitions, and
hardware access. No hardware performance or compatibility is established.
\item Define timing events, workload, deadlines, resource bounds, timeouts,
disconnection behavior, and recovery. No numerical limit is approved.
\item Assess power, physical environment, safety, security, regulatory,
manufacturing, update, and service concerns. External hardware remains outside
the scope; its assumptions and effects on host behavior still need review.
\item Set milestone dates, course access policy, required reviewers, PDF
delivery policy, and the evidence needed for acceptance. Detailed views,
resource budgets, and tests remain planned pending these inputs.
\end{enumerate}
