\section{Boundary and Information Flow}
SP800Project qualifies and publishes sensor data in a host application. The sensor
and ADC0804 produce a conversion code; a clock/counter provides another input
to the FT245R data path. The FT245R and host driver are external dependencies.
The downstream consumer receives published information. The \hyperref[Stakeholder:Operator]{operator} is an
external stakeholder; the interaction mechanism is not yet specified.
Figure~\ref{Figure:SP800Context} records this boundary. It does not prescribe
a device mode, byte encoding, timing source, or hardware implementation.
