SP800Project is a student architecture project owned by A. Crone. Its system of
interest is a host application that qualifies and publishes sensor data.
The sensor, ADC0804, clock/counter, FT245R, and host driver remain external
dependencies. This initial review draft records confirmed project metadata,
the selected boundary, the Embedded Systems profile decision, and owned
engineering questions. It does not establish an approved requirements
baseline or report implementation or hardware test results.
